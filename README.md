# Сравнительный анализ методов визуальной одометрии на данных ALTO

Оценка собственного движения по последовательности аэрофотоснимков. Реализованы
и сравнены три подхода:

| подход | детектор и сопоставление                              |
|---|-------------------------------------------------------|
| SIFT/ORB + Essential Matrix | перебор дескрипторов с проверкой отношения расстояний |
| SIFT/ORB + Lucas-Kanade | пирамидальный оптический поток Лукаса - Канаде        |
| SuperPoint + LightGlue | LightGlue                                             |

Движение восстанавливается двумя способами: через гомографию и через Essential
Matrix. Обе геометрии считаются поверх одних и тех же сопоставлений, поэтому
разница между ними не смешивается с разницей между детекторами.

Анализ ведётся по пяти направлениям: устойчивость ключевых точек, качество
сопоставления, геометрия восстановления движения, накопление ошибки вдоль
маршрута, нагрузка на устройство.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux и macOS

pip install -r requirements.txt
```

Нужен Python 3.11. Файл `requirements.txt` собран под CUDA 13.2; для расчёта на
процессоре уберите суффиксы `+cu132` у `torch` и `torchvision` и строку
`--extra-index-url`. LightGlue ставится из репозитория, версия закреплена хешем
коммита.

## Данные

Датасет ALTO в состав репозитория не входит, его берут из официального
репозитория: https://github.com/MetaSLAM/ALTO

Разложите выборки так:

```
data/
├── train_sample/
│   ├── query_images/     кадры PNG, имена по номеру: 000000.png, 000001.png
│   └── query.csv         телеметрия
└── val_sample/
    ├── query_images/
    └── query.csv
```

## Запуск

Полный порядок работы состоит из двух частей: сначала служебные модули, затем
основной прогон. Конфиг в репозитории уже заполнен, поэтому первую часть можно пропустить и сразу перейти ко второй.

### Служебные модули

```bash
python service/system_info.py         # окружение и версии библиотек
python service/dataset_validator.py   # целостность данных и маршруты
python service/calibration.py         # фокусное расстояние и поворот осей
python service/frame_step.py          # шаг прореживания кадров
```

Первые два проверяют, что окружение собрано и данные пригодны к работе.
Последние два печатают готовые значения, их необходимо занести в `config.py`, в
`CALIBRATION` и `FRAME_STEP` соответственно.

### Основной прогон

```bash
python main.py
```

Программа спросит датасет и нужный анализ.
